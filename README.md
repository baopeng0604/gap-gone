# Gap Gone ✂️🔇

**Gap Gone** 是一个本地录音与音频剪辑工具，专为快速录制人声、跳过静音片段和清理背景噪声而生。基于 **Tauri** 和 **React** 构建。

## ✨ 核心特性

- **🚀 本地极速处理**: 所有处理均在本地完成，无需上传文件，隐私绝对安全。
- **🌊 多行波形乐谱**: 独特的“乐谱式”波形布局，长音频一目了然，无需频繁横向滚动。
- **🤖 智能去静音**: 块级 RMS 分析，先做中值滤波抹掉单块尖峰，再用双阈值滞回判定，底噪波动的段落也能稳定识别；静音阈值可在设置里调（默认 -36.5 dBFS），两端保留量另有紧凑、自然、宽松三档（贴住音频首尾的静音整段切掉，不留尾巴）；检测结果先预览，确认后才应用。
- **🛡️ 非破坏性编辑**: 智能识别仅标记“删除区域”，原文件不受影响。
- **🖱️ 高效交互**:
  - **右键拖拽**: 标记/添加删除区域。
  - **中键拖拽**: 擦除/恢复删除区域。
  - **空格键**: 播放/暂停。
- **本地录音**: 选择输入设备，录音前 2 秒倒计时（「准备」/「开始」），实时查看 RMS/Peak dBFS 电平，录音中可暂停、取消或停止。
- **削波提示**: -6 dBFS 以上显示黄色预警，检测到数字削波时右侧 CLIP 红标锁存，点击即可清除。
- **电平刻度**: 录音长条按 dBFS 从 -60 到 0 每 6 dB 标出一格，越靠右越接近 0 dBFS；-12 ~ -6 dBFS 上画了一条半透明目标带，说话时的峰值落进带里就是期望电平（太低信噪比不够，太高留不出余量）。播放侧竖条的「整段」读数与录音侧的「保持」同为整段样本峰值，两侧量纲一致，不会再出现同一段音频两边读数差十几 dB 的情况。
- **多行波形乐谱**: 每行代表 10 秒，默认 1280×820 窗口完整显示 1000px 波形，最小窗口宽度 1100。
- **非破坏性编辑**: 手动切除、自动检测、恢复、撤销/重做都不会覆盖原始录音。
- **智能降噪**: 桌面端使用标准 DeepFilterNet3 离线处理，提供轻、中、强三档并支持试听。
- **压缩**: 轻 / 中 / 强三档，走「软拐点压缩 → 自动补偿 → 真峰值限幅」一条链：把大的音量压小、小的相对提上来，收窄段落之间的响度差，之后再接响度标准化更稳。全段处理、不支持选区，只改增益不改波形。重复点「压缩」是从处理前的基准重算（等于换档位），不会一层层压下去；不满意可「撤销压缩」。
- **播放时跳过**: 标记的片段在播放和导出时都会跳过，成片时长会缩短。
- **变速不变调**: 左侧竖条提供 0.6～2.0 倍速共八档（每档差 0.2），靠浏览器原生时间伸缩保持音高；同一处还有「从头播放」与循环开关，循环只在成片范围内回环。速度与循环都是试听参数，不影响导出内容。
- **MP3/WAV 导出**: 默认导出 128 kbps 单声道 MP3，可在设置中切换 WAV（48 kHz 单声道 PCM）或调整码率（96/128/192 kbps）。

工具栏分为两行：第一行放播放、选择/切除/恢复/撤销重做、去静音和转录文字（桌面端）；第二行放打开/录音/设置、降噪、压缩、响度标准化、导出和帮助。

## 🛠️ 技术栈

- **Core**: [Tauri v2](https://tauri.app) (Rust)
- **Frontend**: React + TypeScript + Vite
- **Audio Processing**: Web Audio API + Rust/CPAL + DeepFilterNet3

## 📦 安装与运行

### 前提条件

- [Rust](https://www.rust-lang.org/tools/install)（含 cargo）
- [Node.js](https://nodejs.org)（建议 18+）
- **Windows 额外要求**：MSVC Build Tools（含 C++ 桌面开发工作负载）+ WebView2 运行时（Windows 10/11 通常已预装）

### 克隆项目

```bash
git clone https://github.com/your-username/gap-gone.git
cd gap-gone
```

### 安装依赖

```bash
# npm（默认）
npm install

# 或 pnpm
pnpm install
```

> 项目默认配置为 npm（`tauri.conf.json` 中 `beforeBuildCommand` 为 `npm run build`）。切换到 pnpm 时需同步修改该配置并提交 `pnpm-lock.yaml`。

### 启动开发模式

```bash
# npm
npm run tauri dev

# pnpm
pnpm tauri dev
```

开发服务器地址：`http://localhost:1420/`。如果仍显示旧界面，停止旧 Vite 进程后重新运行即可。

### 构建应用

```bash
# npm
npm run tauri build

# pnpm
pnpm tauri build
```

> 首次编译需下载并编译全部 Rust 依赖（含 DeepFilterNet3 + tract），耗时约 30–60 分钟；后续增量编译会快很多。

### 构建产物位置

构建完成后，产物位于 `src-tauri/target/release/`：

| 平台 | 可执行文件 | 安装包 |
|---|---|---|
| **Windows** | `gap-gone.exe` | `bundle/nsis/gap-gone_0.1.0_x64-setup.exe`（NSIS）、`bundle/msi/*.msi`（MSI） |
| **macOS** | `gap-gone.app` | `bundle/dmg/gap-gone_*.dmg` |
| **Linux** | — | `bundle/deb/*.deb`、`bundle/appimage/*.AppImage` |

可执行文件可直接双击运行，安装包用于分发。

### 仅构建前端

```bash
# npm
npm run build

# pnpm
pnpm build
```

输出到 `dist/`。不要直接双击 `dist/index.html`，资源路径和部分 Tauri API 需要通过 HTTP 服务加载。预览前端：

```bash
npm run preview -- --host 127.0.0.1
# 或 pnpm preview --host 127.0.0.1
```

### CI 自动构建（GitHub Actions）

项目内置 `.github/workflows/build-windows.yml`，可在 GitHub Actions 上自动构建 Windows 安装包：

- **手动触发**：仓库 Actions 页面 → 选中 "Build Windows App" → Run workflow（可选择任意分支）
- **推送触发**（可选）：取消 `on.push` 部分的注释即可在推送时自动构建

构建产物会作为 Artifact 上传，可在 Actions 运行页面下载。

## 🎮 使用指南

1. 先打开录音设置选择麦克风（Windows 上默认已选中设备列表的第二个，需要别的设备在这里改），点击 **“确定”** 关闭设置窗口，再点击 **“录音”**，或直接打开音频文件。设置项改完即时生效，**“取消”** 会把本次打开设置后改动过的项目（设备、自动转录、转录面板、静音阈值、响度目标、导出格式与码率、模型目录）回退成打开前的值。
2. 点击录音后先显示 2 秒倒计时（「准备」→「开始」）；倒计时期间可以取消，结束后才开始采集。
3. 录音时查看 RMS、Peak 和峰值保持 dBFS，可点击 **“暂停”**、**“取消”** 或 **“停止录音”**。
4. 停止录音后选择 **“取消”** 或 **“确定并编辑”**。
5. 在编辑页选择去静音预设，点击 **“检测静音”**，检查波形候选区间后点击 **“应用检测”**；不满意时可 **“清除候选”** 或 **“恢复本次检测”**。
6. 使用选择、切除、恢复和撤销/重做工具；选择切除或恢复后也可以直接拖拽波形。左侧竖条可调播放速度（0.6～2.0 倍速，变速不变调）、从头播放和循环播放，都只影响试听，不影响导出。
7. 选择降噪强度，点击 **“一键降噪”**，播放试听后确认或取消。
8. 如各段音量起伏明显，先选压缩档位再点 **“压缩”**：轻档 `-14 dBFS / 1.5:1`、中档（默认）`-18 dBFS / 2:1`、强档 `-22 dBFS / 3:1`，三者都是 6 dB 软拐点。处理链是「软拐点压缩 → 自动补偿（补回平均压缩量，单独试听时响度不变）→ 前瞻真峰值限幅」，全段处理，上限与响度标准化同一口径（WAV `-1 dBTP`、MP3 `-1.5 dBTP`）。处理完会播报平均压缩量与补偿量；换档位再点一次即可，永远从处理前的基准重算，不满意可点 **“撤销压缩”**。
9. 最后点 **“响度标准化”**（快捷键 `⇧L`）：按成片 Integrated 响度归一至设置里的目标（默认 `-23 LUFS`，EBU R128 广播口径；另有播客 `-19`、短视频 `-14`），并用前瞻真峰值限幅把峰值压在 `-1 dBTP`（导出 MP3 时 `-1.5 dBTP`）以内。只改增益、不改波形，所以不会削波也不发毛；不满意可点 **“撤销响度”** 回退。顺序上先压缩后归一：压缩改的是动态，归一是在压缩后的动态上算增益；如果归一点完又回去改压缩档位，归一会被自动作废并提示重新点一次。
10. 满意后点击 **“导出 MP3”**（或设置中切换的格式），保存处理后的音频文件；默认文件名会带有精确到秒的日期时间前缀，例如 `20260823-233600-edited-audio.mp3`。

去静音三档的具体数值（秒）：

| 档位 | 静音最小时长 | 上一句收尾后保留 | 下一句起头前保留 |
| --- | --- | --- | --- |
| 紧凑 | 0.2 | 0.06 | 0.15 |
| 自然（默认） | 0.3 | 0.12 | 0.25 |
| 宽松 | 0.4 | 0.18 | 0.35 |

"下一句起头前"比"上一句收尾后"留得多：检测出的静音末尾容易多咬进下一句的起音，留白不足时下一句会像突然冒出来。贴住音频开头或结尾的静音不设保留量，整段切掉。识别灵敏度另由设置里的 **静音阈值** 控制（默认 -36.5 dBFS）。

## ⌨️ 快捷键与鼠标操作

- `Space`：编辑态播放 / 暂停；录音中暂停 / 继续录音。播放中点击波形会跳转并继续播放，暂停时点击只移动播放头。
- `D`：检测静音并生成候选预览。
- `R`：空闲时开始录音。
- `Shift+R`：恢复最近一次已经应用的自动检测结果，不影响手动切除。
- `S`：录音中停止并进入录音结果预览。
- `⌘/Ctrl+Z`：撤销；`⌘/Ctrl+Shift+Z`：重做。
- `⌘/Ctrl+S`：导出音频（默认 MP3，可在设置中切换 WAV）。
- `O`：打开音频文件。
- `Enter`：录音结束后确定并进入编辑。
- `P`：从头播放（成片开头，已切除的区间跳过）。
- `L`：循环播放开关；点亮即从成片开头开始播放，熄灭即停止播放。
- `⇧L`：一键响度标准化，把成片响度归一至设置里的目标（默认 `-23 LUFS`）。
- `[` / `]`：播放速度减 / 加一档。
- `Esc`：取消录音倒计时、录音中取消并返回编辑页，或取消录音结果；帮助打开时关闭帮助。
- `H` 或 `?`：打开帮助。
- 右键拖拽切除，中键拖拽恢复；左键行为由当前选择、切除或恢复工具决定。

去静音检测与手动编辑使用独立的区间来源。自动检测恢复时只移除自动检测结果，手动切除会继续保留；所有操作都支持撤销和重做。

## DeepFilterNet3

标准模型在桌面端本地运行，不上传音频。模型文件约 8.5 MB，参考实现以 48 kHz 单声道语音为目标，典型算法延迟约 40 ms。第一阶段只做录音后的离线处理，因此不需要约 35 MB 的低延迟模型。降噪不是无损操作，强档可能产生伪影，请保留原始版本并用试听结果选择强度。
