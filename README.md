# Gap Gone ✂️🔇

**Gap Gone** 是一个本地录音与音频剪辑工具，专为快速录制人声、跳过静音片段和清理背景噪声而生。基于 **Tauri** 和 **React** 构建。

![App Screenshot](./screenshot.png) <!-- 你可以在稍后截图放入 -->

## ✨ 核心特性

- **🚀 本地极速处理**: 所有处理均在本地完成，无需上传文件，隐私绝对安全。
- **🌊 多行波形乐谱**: 独特的“乐谱式”波形布局，长音频一目了然，无需频繁横向滚动。
- **🤖 智能去静音**: 块级 RMS 分析，先做中值滤波抹掉单块尖峰，再用双阈值滞回判定，底噪波动的段落也能稳定识别；静音阈值可在设置里调（默认 -36.5 dBFS），两端保留量另有紧凑、自然、宽松三档（贴住音频首尾的静音整段切掉，不留尾巴）；检测结果先预览，确认后才应用。
- **🛡️ 非破坏性编辑**: 智能识别仅标记“删除区域”，原文件不受影响。
- **🖱️ 高效交互**:
  - **右键拖拽**: 标记/添加删除区域。
  - **中键拖拽**: 擦除/恢复删除区域。
  - **空格键**: 播放/暂停。
- **本地录音**: 选择输入设备，录音前 2 秒倒计时（「准备」/「开始」），实时查看 RMS/Peak dBFS 电平，录音中可暂停、取消或停止。
- **削波提示**: -6 dBFS 以上显示黄色预警，检测到数字削波时右侧 CLIP 红标锁存，点击即可清除。
- **电平刻度**: 录音长条按 dBFS 从 -60 到 0 每 6 dB 标出一格：绿色底柱是 **RMS**（说话的平均水平），两根白针分别是**瞬时峰值**与**峰值保持**（停在最高点）；右侧另有 RMS / Peak / 保持三个数字。 -12 ~ -6 dBFS 上的半透明目标带只管**峰值**，看白针落点 —— 底柱（RMS）本来就比峰值低 8 ~ 12 dB，别拿它对着带子看。播放侧竖条同样分两条：填充柱（RMS）+ 白色横针（瞬时峰值），两者逐帧刷新、没有 CSS 过渡，不会拖尾。播放侧的「整段」与录音侧的「保持」同为整段样本峰值，量纲一致。
- **多行波形乐谱**: 每行代表 10 秒，默认 1280×820 窗口完整显示 1000px 波形，最小窗口宽度 1100。
- **非破坏性编辑**: 手动切除、自动检测、恢复、撤销/重做都不会覆盖原始录音。
- **智能降噪**: 桌面端使用 DeepFilterNet3 离线处理，提供轻、中、强三档并支持试听。
- **一键语音优化（「压缩」按钮）**: 轻 / 中 / 强三档，档位＝**目标跨度**（轻 8 / 中 5 / 强 3 dB，即「想把这段录音的动态收窄到多窄」）。点一次跑完整条链路：**高通 80 Hz → 向下扩展 → 软拐点压缩 → 响度标准化**。阈值与压缩比由素材自动生成 —— 先量出这段录音自身的起伏跨度（P90 − P10，已剔除气口，只算保留区间），再反推压缩比 ≈ 跨度 ÷ 目标（封顶 `4:1`）、阈值落在最低的有效段附近；**因为量的是相对跨度，麦克风增益拧大拧小、甚至换一支灵敏度完全不同的麦克风，都不影响判定**，不用为了压缩反复试档。高通削掉隆隆声与近讲低频堆积；向下扩展在停顿与气口处按住底噪（底噪已经足够干净时自动跳过），这样归一把整段抬到目标响度时不会把底噪一起抬起来。**峰值不再靠「补偿」假装**：压缩只收窄动态、不做静态抬升，中间那一步会比处理前小声，最终响度与真峰值由目标 LUFS 与限幅上限共同保证 —— 播报里直接给「最终真峰值 + 限幅衰减」，一眼能看出峰顶到没顶到上限。播报会一次给出链路各步、实测跨度 → 输出跨度、阈值与压缩比、成片有效电平、平均压掉量、响度前 → 后与最终真峰值；素材本来就稳会提示「无需压缩」但仍照常做响度标准化，压缩比顶到上限也会如实说明。「撤销压缩」整体回退到链路之前（含那次归一），「撤销响度」只退归一那一步、保留链路结果。
- **播放时跳过**: 标记的片段在播放和导出时都会跳过，成片时长会缩短。
- **变速不变调**: 左侧竖条提供 0.6～2.0 倍速共八档（每档差 0.2），靠浏览器原生时间伸缩保持音高；同一处还有「从头播放」与循环开关，循环只在成片范围内回环。速度与循环都是试听参数，不影响导出内容。
- **MP3/WAV 导出**: 默认导出 WAV（单声道 16-bit PCM 母版；**采样率跟随录音设备** —— 48 kHz 麦是 48 kHz，44.1 kHz 麦就是 44.1 kHz），可在设置中切换为 MP3 并调整码率（96/128/192 kbps，128 为推荐）。
- **🎬 视频剪辑（桌面端）**: 「打开视频」导入 MP4/MOV/MKV 等容器，自动抽出音轨进同一套波形/去静音/切除/降噪/响度管线，画面随播放同步预览；导出时把剪辑结果与处理过的音轨一起写成 MP4。默认走**无损快速**（画面不重编码、音轨原样拷贝、秒级完成），需要切点精确到帧时切到**精确重编码**。看过转录结果后，还能勾选一并导出一份**按成片时间轴重映射**的 `.srt` 字幕。**依赖系统安装的 ffmpeg**（不随应用打包），没装时界面会给出安装指引，也可以手动指定路径。
  - **素材范围**：H.264 与 **HEVC（H.265）** 的常见容器都可以导入，手机竖拍的带旋转素材也支持；**HEVC 与带旋转的素材会自动走「精确重编码」**（HEVC 转成 H.264，兼容性更好），因为不重编码的快速档在这两类素材上会丢画面或方向出错。
  - **想用「无损快速」剪得准，把 OBS 的关键帧间隔改成 1 秒**：**设置 → 输出 → 输出模式改成「高级」→ 切到「录像」标签页 → 「关键帧间隔」填 `1`**（`0` = 自动；实测自动在 1080p30 下等于 250 帧 = **8.33 秒**）。改完点「应用」。
    切到高级模式时有三处必须顺手确认，否则会踩坑：① **录像编码器要重新选一次**（高级模式的编码器是独立配置，没选可能退成 CPU 软编：AMD 显卡选「AMD HW H.264 (AVC)」、NVIDIA 选「NVIDIA NVENC H.264」）；② **高级模式的录像路径与码率是另一套**（和简单模式互不相同），确认路径是你想要的文件夹、码率别设太低（1080p30 口播建议 CQP 20 附近，或 CBR 8000~10000 kbps）；③ **改设置只对之后录的生效**，已录好的素材仍是旧间隔，处理时会自动走精确重编码。

工具栏分为两行：第一行放播放、选择/切除/恢复/撤销重做、去静音和转录文字（桌面端）；第二行放打开/打开视频/录音/设置、降噪、压缩、响度标准化、导出和帮助。

## 🛠️ 技术栈

- **Core**: [Tauri v2](https://tauri.app) (Rust)
- **Frontend**: React + TypeScript + Vite
- **Audio Processing**: Web Audio API + Rust/CPAL + DeepFilterNet3
- **Video（可选）**: 系统安装的 [ffmpeg](https://ffmpeg.org)（调用其 CLI，不随应用分发）

## 📦 安装与运行

### 前提条件

- [Rust](https://www.rust-lang.org/tools/install)（含 cargo）
- [Node.js](https://nodejs.org)（建议 18+）
- **Windows 额外要求**：MSVC Build Tools（含 C++ 桌面开发工作负载）+ WebView2 运行时（Windows 10/11 通常已预装）
- **视频功能额外要求**：系统安装 [ffmpeg](https://ffmpeg.org/download.html)（含 `ffprobe`，winget / brew / scoop 的发行包都成对提供）。应用不内置 ffmpeg，未安装时点「打开视频」会弹安装指引，也可以手动指定可执行文件路径。**系统里可能同时有好几份 ffmpeg**（不少软件自带精简构建，实测 Krita 自带的那份既没有 libx264 也没有 lavfi）：应用会优先选带 libx264 的那一份，「精确重编码」档依赖它，缺了会在界面上提示你另指一份完整构建。

### 克隆项目

```bash
git clone https://github.com/your-username/gap-gone.git
cd gap-gone
```

### 安装依赖

```bash
# npm（默认）
npm install

# 或 pnpm
pnpm install
```

> 项目默认配置为 npm（`tauri.conf.json` 中 `beforeBuildCommand` 为 `npm run build`）。切换到 pnpm 时需同步修改该配置并提交 `pnpm-lock.yaml`。

### 启动开发模式

```bash
# npm
npm run tauri dev

# pnpm
pnpm tauri dev
```

开发服务器地址：`http://localhost:1420/`。如果仍显示旧界面，停止旧 Vite 进程后重新运行即可。

```bash

npm run tauri build

# pnpm
pnpm tauri build
```

> 首次编译需下载并编译全部 Rust 依赖（含 DeepFilterNet3 + tract），耗时约 30–60 分钟；后续增量编译会快很多。

## 🎮 使用指南

1. 先打开录音设置选择麦克风（Windows 上默认已选中设备列表的第二个，需要别的设备在这里改），点击 **“确定”** 关闭设置窗口，再点击 **“录音”**，或直接打开音频文件。设置项改完即时生效，**“取消”** 会把本次打开设置后改动过的项目（设备、自动转录、转录面板、静音阈值、响度目标、导出格式与码率、模型目录）回退成打开前的值。
2. 点击录音后先显示 2 秒倒计时（「准备」→「开始」）；倒计时期间可以取消，结束后才开始采集。
3. 录音时查看 RMS、Peak 和峰值保持 dBFS，可点击 **“暂停”**、**“取消”** 或 **“停止录音”**。
4. 停止录音后选择 **“取消”** 或 **“确定并编辑”**。
5. 在编辑页选择去静音预设，点击 **“检测静音”**，检查波形候选区间后点击 **“应用检测”**；不满意时可 **“清除候选”** 或 **“恢复本次检测”**。
6. 使用选择、切除、恢复和撤销/重做工具；选择切除或恢复后也可以直接拖拽波形。左侧竖条可调播放速度（0.6～2.0 倍速，变速不变调）、从头播放和循环播放，都只影响试听，不影响导出。
7. 选择降噪强度，点击 **“一键降噪”**，播放试听后确认或取消。
8. 如各段音量起伏明显，先选压缩档位再点 **“压缩”**：档位表示**目标跨度**——轻档压到 `8 dB`、中档（默认）`5 dB`、强档 `3 dB`，指的是「想把这段录音的动态收窄到多窄」。阈值和压缩比不用你管：程序先量出这段录音自身的起伏跨度（P90 − P10，已剔除气口，只算保留区间），再反推压缩比 ≈ 跨度 ÷ 目标（封顶 `4:1`）与阈值（落在最低的有效段附近，配 6 dB 软拐点）；**量的是相对跨度，麦克风增益拧大拧小、甚至换一支灵敏度完全不同的麦克风都不影响判定**，不必反复试档。点这一次跑完整条链路：**高通 80 Hz → 向下扩展 → 软拐点压缩 → 响度标准化**。高通削掉隆隆声与近讲低频堆积；向下扩展在停顿与气口处按住底噪（底噪已经足够干净时自动跳过，播报会说明），这样归一把整段抬到目标响度时不会把底噪一起抬起来 —— 所以按钮旁会提示 **“建议先降噪”**，扩展器只兜得住残余底噪，先降噪成品更干净。**注意：压缩不做静态补偿，中间那一步会比处理前小声，这是正常的**，最终响度由目标 LUFS 决定；该看的是播报末尾的「最终真峰值 + 限幅衰减」。上限与「响度标准化」按钮同一口径（WAV `-1 dBTP`、MP3 `-1.5 dBTP`）。播报会一次给出链路各步、实测跨度 → 输出跨度、生成的阈值与压缩比、成片有效电平、平均压掉量，以及响度前 → 后与最终真峰值：跨度已经和目标差不多了会提示「无需压缩」（那一档不动动态，但照常做响度标准化），压缩比顶到 `4:1` 仍压不够也会如实说明。换档位再点一次即可，永远从链路之前的基准重算；不满意可点 **“撤销压缩”** 整体回退（含那次归一），或点 **“撤销响度”** 只退归一、保留链路结果。
9. 需要单独调响度、不动动态时，点 **“响度标准化”**（快捷键 `⇧L`）：按成片 Integrated 响度归一至设置里的目标（默认 `-19 LUFS`，Apple Podcasts 单声道口径；另有广播 `-23`、短视频 `-14`），并用前瞻真峰值限幅把峰值压在 `-1 dBTP`（导出 MP3 时 `-1.5 dBTP`）以内。只改增益、不改波形，所以不会削波也不发毛；不满意可点 **“撤销响度”** 回退。这一步与链路末尾那次归一用的是同一套算法，所以压过之后再点它通常不会有明显变化。
10. 满意后点击 **“导出 WAV”**（默认格式，设置里可切成 MP3），保存处理后的音频文件；默认文件名会带有精确到秒的日期时间前缀，例如 `20260823-233600-edited-audio.wav`。
11. 要处理视频时点 **“打开视频”**：抽出的音轨进同一套编辑流程，波形上方的画面随播放同步。**导出按钮会变成“导出视频”**，旁边多两件东西：
    - **导出档位**。默认 **「无损快速」**：画面不重编码、音轨原样拷贝，秒级出片。它**只能从关键帧起切**，所以只有本次切点都落在关键帧上时才可用（档位旁会写明原因）；否则会自动改用 **「精确重编码」**，切点精确到帧，代价是慢（长视频几分钟到几十分钟）且有损，并要求所选 ffmpeg 带 libx264（缺了会提示你另指一份）。**OBS 默认的关键帧间隔很长（实测 8.3 秒），那种素材上「无损快速」只能按关键帧粗切** —— 改法见上面「核心特性」里的 OBS 设置步骤。
    - **「字幕 SRT」勾选**（先转录过才可勾）：勾上会在导出视频的同时，写一份同名 `.srt` 到视频旁边。字幕时间码已经**按成片时间轴重映射**（跳过被切除的区间），不用自己再对时间。**烧录进画面还没做**，这一步只产出外挂字幕文件。

去静音三档的具体数值（秒）：

| 档位 | 静音最小时长 | 上一句收尾后保留 | 下一句起头前保留 |
| --- | --- | --- | --- |
| 紧凑 | 0.2 | 0.06 | 0.15 |
| 自然（默认） | 0.3 | 0.12 | 0.25 |
| 宽松 | 0.4 | 0.18 | 0.35 |

"下一句起头前"比"上一句收尾后"留得多：检测出的静音末尾容易多咬进下一句的起音，留白不足时下一句会像突然冒出来。贴住音频开头或结尾的静音不设保留量，整段切掉。识别灵敏度另由设置里的 **静音阈值** 控制（默认 -36.5 dBFS）。

## ⌨️ 快捷键与鼠标操作

- `Space`：编辑态播放 / 暂停；录音中暂停 / 继续录音。播放中点击波形会跳转并继续播放，暂停时点击只移动播放头。
- `D`：检测静音并生成候选预览。
- `R`：空闲时开始录音。
- `Shift+R`：恢复最近一次已经应用的自动检测结果，不影响手动切除。
- `S`：录音中停止并进入录音结果预览。
- `⌘/Ctrl+Z`：撤销；`⌘/Ctrl+Shift+Z`：重做。
- `⌘/Ctrl+S`：导出音频（默认 WAV，可在设置中切换 MP3）。
- `O`：打开音频文件。
- `Enter`：录音结束后确定并进入编辑。
- `P`：从头播放（成片开头，已切除的区间跳过）。
- `L`：循环播放开关；点亮即从成片开头开始播放，熄灭即停止播放。
- `⇧L`：一键响度标准化，把成片响度归一至设置里的目标（默认 `-19 LUFS`）。
- `[` / `]`：播放速度减 / 加一档。
- `Esc`：取消录音倒计时、录音中取消并返回编辑页，或取消录音结果；帮助打开时关闭帮助。
- `H` 或 `?`：打开帮助。
- 右键拖拽切除，中键拖拽恢复；左键行为由当前选择、切除或恢复工具决定。

去静音检测与手动编辑使用独立的区间来源。自动检测恢复时只移除自动检测结果，手动切除会继续保留；所有操作都支持撤销和重做。

## DeepFilterNet3

模型在桌面端本地运行，不上传音频。参考实现以 48 kHz 单声道语音为目标；处理链的算法延迟为 480 采样（48 kHz 下 10 ms），已做补偿，因此降噪结果与原始时间轴逐采样对齐。当前内置的是**低延迟变体（约 35 MB）** —— 标准变体更小（7.6 MB），但它的计算图在当前锁定的推理引擎版本上连加载都会失败，所以只能先用低延迟版（详见 AGENTS.md 硬约束 18）。降噪不是无损操作，强档可能产生伪影，请保留原始版本并用试听结果选择强度。
