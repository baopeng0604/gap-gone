# 波形跟随居中 + 左对齐 + 右侧固定栏 优化计划

## 概要

三项改动，全部在前端（`src/`），不涉及 Rust：

1. **播放跟随居中**：播放时当前波形行始终滚动到视口居中（替代现有「滚出视口才拉动」逻辑）。
2. **左对齐**：波形区与转录栏宽度统一为 1100px（与工具栏 `min-width` 一致），居中对齐后左右边缘均对齐。
3. **右侧固定栏**：新增固定定位侧栏——上半部为播放实时音量竖排刻度图（-24/-18/-12/-6 dB），底部为「回到波形顶部」按钮。仅播放时显示实时电平（AnalyserNode 分析），录音面板现有横向电平表保持不动。

## 现状分析（Phase 1 探索结论）

* 播放跟随逻辑在 [App.tsx#L192-L209](../src/App.tsx)：仅当行完全滚出视口（`rect.top >= 110 && rect.bottom <= window.innerHeight`）才 `scrollIntoView({ block: "center" })`。问题：底部判定用的是整个视口，没扣除吸底转录面板（约 190px），行被转录面板遮住时不会触发滚动。

* 工具栏 `.controls` 实际宽度 `min-width: min(1100px, calc(100vw - 2rem))` 居中；波形容器 `.waveform-score-container` 固定 1000px 居中；转录栏 `min(1000px, ...)` 居中 → 左边缘差 50px。

* 波形行宽是 JS 传入的像素值：[WaveformRow.tsx#L247](../src/components/WaveformRow.tsx) `width = 1000` 默认值（`WaveformScore` 未传 width，行内 canvas 按此绘制）。每行 10 秒（`secondsPerRow = 10`）。

* 播放链路：`startPlayback` → `playSegment` 里 `source.connect(context.destination)` → rAF `animate` 循环 `setPosition`。目前无任何播放音量分析。

* dB 刻度常量 `METER_MARKS = [-24, -18, -12, -6, -3]`、`METER_MIN_DB = -30`、`meterPosition()` 目前是 App.tsx 内部函数，服务于录音面板横向电平表。

* 页面垂直滚动发生在 window（`.container` 无 overflow-y），所以「回到顶部」= `window.scrollTo`。

## 改动清单

### 1. `src/App.tsx` — 播放跟随居中

替换 [L192-L209](../src/App.tsx) 的 useEffect：

```ts
// 播放跟随：当前行变化时（含点击转录句/波形跳转），把该行滚动到视口居中，
// 上下行都能看到，方便对照调整。
useEffect(() => {
  followRowRef.current = -1;
}, [audioBuffer]);

useEffect(() => {
  if (!audioBuffer) return;
  const rowIndex = Math.floor(currentTime / 10);
  if (rowIndex === followRowRef.current) return;
  followRowRef.current = rowIndex;
  const container =
    waveformViewRef.current?.querySelector(".waveform-score-container");
  const row = container?.children[rowIndex] as HTMLElement | undefined;
  row?.scrollIntoView({ block: "center", behavior: "smooth" });
}, [currentTime, audioBuffer]);
```

要点：

* 去掉 `isPlaying` 守卫和可见性判断——点击转录句跳转（暂停态）也会居中对应行；行索引不变时早退，不影响用户手动浏览。

* `audioBuffer` 变化时重置 `followRowRef`，新文件播放从第 0 行也能触发滚动。

### 2. `src/App.tsx` + 新组件 `src/components/WaveSidebar.tsx` — 播放音量分析 + 右侧固定栏

**App.tsx 新增：**

* `const analyserRef = useRef<AnalyserNode | null>(null);`

* `const [playbackLevel, setPlaybackLevel] = useState<{ rmsDb: number; peakDb: number } | null>(null);`

* AudioContext 初始化 effect（[L153-L177](../src/App.tsx)）里创建常驻 AnalyserNode：`analyser.fftSize = 2048`，`analyser.connect(context.destination)`，存入 `analyserRef`。

* `playSegment` 中改为 `source.connect(analyserRef.current)` （原来是 `context.destination`），所有播放路径（含降噪试听）都经过 analyser。

* `startPlayback` 的 `animate` 循环里（`setPosition` 之后）读取 `getFloatTimeDomainData` 计算 RMS/Peak，转 dB（`20 * Math.log10`，下限 -Infinity），`setPlaybackLevel(...)`。Float32Array 在 `startPlayback` 闭包外层分配一次复用。App 播放期间本就每帧 re-render（`setCurrentTime`），无额外性能顾虑。

* `stopPlayback` 及播放自然结束（`source.onended` 末段分支）里 `setPlaybackLevel(null)`，刻度回落。

* 渲染：`{audioBuffer && <WaveSidebar level={playbackLevel} />}`，放在 `<main>` 内、`waveform-view` 之后。

**新组件** **`src/components/WaveSidebar.tsx`：**

```tsx
interface WaveSidebarProps {
  level: { rmsDb: number; peakDb: number } | null;
}
```

* 结构：`<aside className="wave-sidebar">` → 上部 `.sidebar-meter`（竖排电平表，flex 布局占上半区）+ 底部 `.sidebar-top-btn`（回到顶部按钮）。

* 电平表：竖向轨道（背景渐变自下而上绿→黄→红，复用横向表的配色语言），RMS 填充条自底部按 `meterPosition(rmsDb)` 高度百分比撑起（60ms linear transition），白色 Peak 横线按峰值定位；刻度标记 `-24 / -18 / -12 / -6`（用户指定的四个，不含 -3）按位置画在轨道上并带文字标签；顶部显示当前 RMS 数值读数（如 `-18.4 dB`，无信号时 `-∞`）。

* 组件内自定义常量：`MIN_DB = -30`、`MARKS = [-24, -18, -12, -6]`、本地 `meterPosition()`（App.tsx 的是私有函数，不强行抽公共模块，避免为一次性使用过度抽象）。

* 回到顶部按钮：`onClick={() => window.scrollTo({ top: 0, behavior: "smooth" })}`，文案「回到顶部」，带 `↑` 图标字符。快捷键无需新增（点击即用）。

### 3. `src/components/WaveformRow.tsx` — 行宽 1000 → 1100

[L247](../src/components/WaveformRow.tsx) 默认参数 `width = 1000` → `width = 1100`（`WaveformScore` 未传 width，canvas 按此重绘；`WaveformCanvas` 自身的默认值无人使用，顺手同步改成 1100 保持一致）。

### 4. `src/App.css` — 对齐 + 侧栏样式

* `.waveform-score-container`：`width: 1000px; max-width: 1000px` → `width: min(1100px, 100%); max-width: 100%`（保持 `margin: 0 auto`）。用 `100%` 而非 `calc(100vw - 2rem)`，避免 100vw 含滚动条导致的横向溢出；居中 + 等宽 ⇒ 与工具栏左边缘对齐。

* `.transcript-panel`：`width: min(1000px, calc(100vw - 2rem))` → `width: min(1100px, calc(100vw - 2rem))`（与 `.controls` 同款宽度公式）。

* 新增：

```css
.wave-sidebar {
  position: fixed;
  top: 6.5rem;      /* 吸顶工具栏（约 90px + 0.5rem 顶距）之下 */
  right: 1rem;
  bottom: 1rem;     /* 视口右下角；宽屏下与居中的转录栏并排不重叠 */
  width: 92px;
  display: flex;
  flex-direction: column;
  align-items: center;
  z-index: 25;
  pointer-events: none; /* 容器穿透，仅按钮可点 */
}

.sidebar-meter { /* 高度约 38vh，上限 420px */ }
.sidebar-meter-track { /* 40px 宽竖向轨道 + 渐变背景 */ }
.sidebar-meter-fill { /* RMS 填充，transform/height 60ms linear */ }
.sidebar-meter-peak { /* 2px 白色横线 */ }
.sidebar-meter-tick { /* 刻度线 */ }
.sidebar-meter-label { /* -24/-18/-12/-6 标签 */ }
.sidebar-meter-readout { /* 顶部实时读数，等宽字体 */ }
.sidebar-top-btn { pointer-events: auto; /* 贴栏底（=视口右下角） */ }

/* 窄屏隐藏：视口 < 1380px 时侧栏会压到 1100px 内容区右缘 */
@media (max-width: 1379px) {
  .wave-sidebar { display: none; }
}
```

阈值推导：内容区（1100px 居中）右缘 = `(vw + 1100) / 2`；侧栏左缘 ≈ `vw - 104`。不重叠要求 `vw ≥ ~1310`，留余量取 1380。

### 5. `README.md` — 同步一句描述

L20 「默认 1200×800 窗口完整显示 1000px 波形」→ 1100px。仅此一处口径更新，不新增文档。

## 假设与决策

* 「左对齐」通过「三者统一 1100px + 同居中」实现（左右边缘同时对齐）；工具栏 `fit-content` 超宽的极端情形不处理。

* 播放期间用户手动滚开页面，下一个 10 秒行切换时会被拉回居中——这是用户明确要求的行为（「把当前播放的那一行放在页面居中的位置」）。

* 侧栏仅在 `audioBuffer` 存在时渲染；录音期间侧栏可见但电平表无信号（用户已确认仅播放时显示）。

* 削波 CLIP 指示、峰值保持等能力仍留在录音面板，不迁移。

* 侧栏在窄于 1380px 的窗口整体隐藏（fixed 定位避免遮挡内容），不做响应式降级布局。

## 验证步骤

1. `pnpm build`：tsc 类型检查 + Vite 构建通过。
2. `pnpm tauri dev` 手动验证：

   * 打开/录制一段长音频（≥ 2 分钟），播放：当前行每 10 秒切换时滚动到视口居中，上一行/下一行同时可见；底部转录面板不再遮挡播放行。

   * 暂停时点击转录面板某句 → 对应波形行居中。

   * 工具栏、波形区、转录栏左边缘对齐（宽窗口下三者同宽 1100px）。

   * 播放时右侧竖排电平表随声音实时起伏，-24/-18/-12/-6 刻度位置正确（可用已知电平音频核对）；暂停后回落。

   * 播放到 15 分钟级别长音频尾部，点击「回到顶部」→ 平滑滚回波形顶部。

   * 窗口缩到 < 1380px：侧栏隐藏，无遮挡；录音流程的横向电平表、CLIP 指示不受影响。
